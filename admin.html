Document Translator (HE ↔ EN)
Drop a .docx / .txt / .md / .csv / .html file → GPT translates in either direction → download in the SAME format with all styling preserved · auto-detects source language
Translating…
Output format per input: .docx / .odt / .pptx / .xlsx / .rtf / .mqxlz / .mqxliff / .txt / .md / .csv / .html → same format with all styling preserved · .pdf → .docx (text + paragraphs extracted; PDF visual styling cannot be cleanly round-tripped, but Word can re-export to PDF in one click). For heavily-formatted documents with mid-sentence inline styling (a bold word in the middle of a paragraph), translation is applied per text-run independently — formatting survives, but split-sentence quality may dip. For .xlsx, only string cells are translated; numbers, dates, and formulas pass through untouched. For .rtf, ASCII-source RTF (English) translates cleanly; Hebrew-source RTF using \u####? escapes is best converted to .docx first.
