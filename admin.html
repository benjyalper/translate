Document Translator (HE ↔ EN)
Drop a .docx / .txt / .md / .csv / .html file → GPT translates in either direction → download in the SAME format with all styling preserved · auto-detects source language
🧪 Localization Test Mode (glossary + style guide + context-column-aware; .xlsx only)
What this mode does differently: translates only the source column into the target column · feeds the context column into each GPT call · matches glossary terms in each source string and pins them to their fixed Hebrew renderings · honors DNT ("Do Not Translate") glossary rules · masks placeholders like {s_num}, %d%, \n, ICU one:/other: keys so they survive untouched · processes one segment at a time for max quality.
Translating…
Output format per input: .docx / .odt / .pptx / .xlsx / .rtf / .mqxlz / .mqxliff / .txt / .md / .csv / .html → same format with all styling preserved · .pdf → .docx (text + paragraphs extracted; PDF visual styling cannot be cleanly round-tripped, but Word can re-export to PDF in one click). For heavily-formatted documents with mid-sentence inline styling (a bold word in the middle of a paragraph), translation is applied per text-run independently — formatting survives, but split-sentence quality may dip. For .xlsx, only string cells are translated; numbers, dates, and formulas pass through untouched. For .rtf, ASCII-source RTF (English) translates cleanly; Hebrew-source RTF using \u####? escapes is best converted to .docx first.

Starling Copy Deck
Raw Starling XLIFF → Proofread / Translate with GPT-5.4 → copy-paste-ready segment cards (placeholders & tags kept verbatim)
ℹ️ How this works — the Starling workflow
Starling has no re-import, so edits get back in only by pasting each cell by hand. This tool does the whole round trip and lets you paste segments while Claude edits others in the browser at the same time.
  1. You open the Starling task → Export → Xliff → download → drop the raw file below → Build copy deck.
  2. Click 📑 Proofread (fix grammar/terminology + convert to plural gender-neutral) or 🌐 Translate source → HE. GPT-5.4 processes every segment in your browser with your OpenAI key, keeping each placeholder / <tag> / HTML verbatim.
  3. Review the cards. Segments with a ⚠ tag hold a real inline tag object — place those in the Starling editor by hand rather than pasting.
  4. Click Copy on a card → paste into the Starling cell (Starling re-chips {tokens} & <tags> automatically) → tick pasted. Progress is saved in this browser.
Working simultaneously? Decide up front who takes which segments / files so you don't both edit the same cell. Also accepts a ready deck JSON or a {"<seg>":{cat,note,target}} map that Claude produces — then just skip the GPT step.
